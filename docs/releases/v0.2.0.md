# AI Intel Workbench v0.2.0

v0.2.0 upgrades the project from a fixed-source daily digest into a quality-gated intelligence workflow for emerging topics, major Chinese AI labs, and attributable X viewpoints.

## Highlights

### Domestic AI lab coverage

- Adds daily checks for Qwen, DeepSeek, Kimi/Moonshot, Z.ai/GLM, ByteDance Seed/Doubao, Tencent Hunyuan, Baidu ERNIE, and MiniMax.
- Adds an extended rotating pool for StepFun, Huawei Pangu, InternLM, Meituan LongCat, Xiaomi MiMo, and InclusionAI.
- Separates `model_release`, `product_ops`, and `research` so product rollouts, pricing/quota/capacity changes, developer tools, and papers cannot be hidden by model-launch coverage.
- Distinguishes announcements, hosted previews, API/product availability, and released weights.

### Topic-driven KOL discovery

- Expands the default KOL seed list from 61 to 69 entries.
- Treats the static list as a watch pool rather than a discovery ceiling.
- Requires major topics to include originators, independent evaluations, and counterpoints where evidence is available.
- Adds topic expansion for exact model names, article titles, coined terms, evaluators, and counterarguments.

### Quality version 4

- Expands mandatory coverage from four to eight query groups.
- Adds structured `lab_pipeline` and `viewpoint_pipeline` records to `coverage_report`.
- Requires all eight core domestic labs and all three lab activity tracks to be checked.
- Keeps freshness, concrete X evidence, article deep links, cross-day deduplication, and publish-on-valid gates.

### Safer X and Lark workflows

- Gate CLI remains candidate discovery only; synthesized answers without cited posts are rejected.
- Scheduled runs use public indexed evidence and do not automate a logged-in X session.
- Lark scheduled pushes now use a fail-closed `primary_only` policy and never log webhook fragments.

### Dashboard and archive

- Sorts archived digests newest first.
- Adds dimension, heat, and keyword filters.
- Adds pagination and page-size controls for larger archives.
- Includes public digest history through 2026-07-21.

## Validation

- All YAML configuration files parse successfully.
- Python scripts compile successfully.
- All newly published July digest archives pass the repository validator.
- The 2026-07-21 quality-v4 digest completes 8/8 coverage groups, contains 20/21 items from the last seven days, and has concrete X evidence for 8/9 KOL items.
- No local webhook, token, cookie, password, or user-specific path is included in the release.

## Upgrade notes

- Existing legacy digests remain readable and are validated in compatibility mode.
- New production digests should use `quality_version: 4`.
- Keep real bot webhooks in `config/secrets.env` or environment variables; never add them to `config/push.yaml`.
- Scheduled runs should write with `--publish-on-valid` and push only after validation succeeds.
